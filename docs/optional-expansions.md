# 待选择的新增功能

当前默认界面已按用户要求恢复 Git HEAD 中的原首页、原布局和导航、原工具库、原提交页面及手动计算器。根地址恢复跳转 `/zh`。新增能力的代码与增量数据库保留，但不再接入默认前端路由；不会自动替换原页面。

| 可选扩充 | 已实现内容 | 可考虑的接入位置 |
|---|---|---|
| 核验产品目录 | 四类产品、套餐、来源、核验时间 | 原工具库新增入口，不覆盖原目录 |
| 搜索和价格筛选 | 模糊搜索、套餐级多计费方式、同单位价格筛选 | 逐项加入原搜索与筛选区域 |
| 低价平替 | 定向关系、推荐依据、条件化价格差异 | 产品详情新增模块 |
| 多产品比较 | 套餐、免费额度、限制、官方来源对照 | 原比较入口 |
| 四类成本计算器 | 图片、视频、语音、音乐，用量成本与节省 | 原手动计算器旁新增选项 |
| 数据管理 | 校验、发布、来源、审核、价格历史 | 后台独立接入 |
| SEO | metadata、canonical、结构化数据、预渲染 | 仅在选定的新页面上线时启用 |
| 新版首页和布局 | 价格决策首页及紧凑目录样式 | 暂不采用，保留代码 |

恢复不会删除用户的手动计算本地存储，也不回滚数据库或删除已录入数据。原工具库依旧使用原版本的 Mock 数据；恢复视觉并不代表这些示例价格经过核验。

实现位置：`src/frontend/catalog/`、`src/shared/catalog/`、`src/worker/routes/catalog.ts`。新增路由及页面服务接线参考分别保存在 `docs/expansion-app.tsx.txt` 和 `docs/expansion-worker.ts.txt`，不是默认运行入口。扩充版提交组件保存为 `src/frontend/catalog/SubmitExpansion.tsx`。

默认构建为 `npm run build`（原版界面）。`build:catalog-preview` 仅保留旧预渲染流程供后续接回新版路由时使用；当前不能作为完整新版预览构建使用。

恢复验证：类型检查、72 项测试及原版生产构建通过；桌面/移动页面另外检查。
