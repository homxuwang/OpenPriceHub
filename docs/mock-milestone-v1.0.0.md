# OpenPriceHub Mock First 阶段存档

版本：v1.0.0

日期：2026-11-16 UTC

定位：Mock 阶段历史基线；不代表生产上线验收。

后续进展：本文列出的统一 Repository、旧写接口鉴权和账户/动态运营能力已在后续本地实现，详见[三项整改报告](./real-data-operations-v1.0.0.md)。生产部署和真实域名 TXT 的最终验收仍需实际环境。

## 已完成

- 保留现有前端架构及 UI，首页搜索、类别入口、导航与广告位预留。
- 图片、视频、TTS、音乐、LLM/API 的 Mock First 需求筛选和核心业务验证。
- 模型成本计算器 P0—P4：分类和单位隔离、精确计价、整包购买、额度和超额、阶梯与固定费、手动汇率、快速/详细模式、JSON 预览备份及转存。
- 独立开发者网站提交，管理员编辑、审核及版本化发布，独立公开渠道报价页面。
- D1 增量 Migration、配置驱动的 Cloudflare 备份/迁移/部署脚本、密钥隔离、离线计划和失败中止。
- 自动化及浏览器测试、阶段报告；正式配置、密钥、数据库及备份不进入 Git。

## 尚未完成

- 当前主工具列表仍读取本地 Mock；产品详情、独立比较和平替页尚未接入主流程。
- 新的渠道报价与旧目录属于两个发布域，尚未统一为主流程的真实产品/模型/渠道/套餐 Repository。
- 旧 platforms/models 的写接口权限尚需补齐，不能将开发环境视为生产可直接开放状态。
- 尚未执行真实 Cloudflare 远程迁移、部署及备份恢复演练。
- 每日来源检查、自动采集、自动汇率、多管理员账户、开发者自助账户和域名所有权验证尚未交付。

## 下一阶段建议：真实数据最小闭环

1. **统一数据契约与权限**：复用现有 Repository 和计算引擎，明确产品、模型、服务渠道、套餐身份与计价规则；统一公开读取，所有管理写入鉴权。保留 Mock 作为测试数据源。
2. **隔离 D1 / Cloudflare staging 验证**：使用独立绑定和密钥，先备份并测试 Migration，验证原数据兼容和恢复；通过管理员录入少量有来源的真实报价，空价、过期、额度和参数限制保持明确。
3. **接通三个决策页面**：沿用现有 UI 完成产品详情、独立比较和平替。统一读取同一已发布版本；同一用量条件下计算实际购买成本，不自动覆盖用户的本地计算器档案。
4. **完成后再做动态更新与生产切换**：先人工审核发布，随后启用每天一次的来源检查，稳定后再考虑一天两次；核对缓存、动态 SEO、日志和失败恢复后再部署生产。

建议先选 5—10 个明确身份的模型或产品，其中至少有若干同模型官方/第三方报价对，验证“找到产品 → 看套餐 → 同条件比较 → 算购买成本 → 访问来源”的完整流程。暂不扩大 Mock 数量或启动大规模抓取。
