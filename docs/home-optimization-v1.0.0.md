# OpenPriceHub 首页增量优化

版本：v1.0.0

日期：2026-11-13 UTC

## 变更

保留现有配色、卡片、字体、导航和组件体系，调整首页信息顺序为：标题与搜索 → 五类创作入口 → 两个成本工具 → 分类切换的工具与套餐 → 价格记录展示 → 比较提示与价格维护 → 赞助位样例。

- 首屏文案强调按创作需求选工具、对比套餐、计算相同用量成本；英文保留 Find Better AI Tools. Spend Less.
- 首屏展示「智能选型与比价（模拟体验）」及「模型成本计算器」，后续两张卡片解释各自用途。
- 图片、视频、语音、音乐、LLM/API 五类入口与导航一致；桌面五列、移动两列，复用紧凑 ScenarioCard。
- 三组热门卡片合并为一个分类切换区，每类最多展示四个条目；按已有目录顺序展示，不使用示例热度或异构价格排名。
- 首页工具卡片标明示例价格，隐藏官方/已核验、商用权限徽章及尚未可用的产品详情/对比按钮；浏览操作进入工具库搜索。
- 语音和音乐暂无该目录价格记录，展示空状态，并进入已有手动语音/音乐比较器，不补造数据。
- 价格变动仅作为历史样例格式展示，不声称最新变化或本次核验。赞助位移至后方，逐卡标记展示样例，不声称实际合作。
- 首页原热门对比和指南详情仍是占位页，因此不再作为首页主内容操作入口。保留指南主题为就地阅读的比较提示，操作转向对应场景计算器；原路由和数据未删除。
- 价格维护操作进入可实际保存、导出数据的计算器；原提交页及导航保留。未承诺尚未接通的审核发布流程。

## 搜索

复用 SearchBar 增加模糊候选、单选直达、键盘选择和中英文搜索按钮。

工具候选来自当前目录；模型及网站/服务商候选来自当前浏览器已保存的详细计算器档案。后者通过模型/平台 ID 直接进入计算器并预选，不从工具描述猜测产品—模型关系，不制造服务商或实时报价。没有保存记录时不会展示不存在的个人模型。

## 计算器预选

/calculator?type=image、video、tts、music、api（映射 LLM/API）真正初始化使用场景。支持别名 voice/text/llm-api，未知值回退全部。model/platform 参数支持从个人搜索候选直达。

详细模式只过滤参与比较的模型，维护档案仍保留全部数据；快速模式只展示当前类别规则，新增规则采用当前类别。切换全部场景恢复展示。场景过滤不会删除原始记录，不改变导出内容和本地存储键，也不推进待验收的购买金额或复杂计价阶段。
