## 交付范围

基于原 /zh/calculator 与 /en/calculator 增量修改，保留详细模式、快速模式、网站/套餐/模型/规则维护、本地保存、JSON 导入导出及详细模式图表。结果展示提取为共用组件，避免两种模式重复实现不同的安全规则。

1. 图片、视频、TTS、音乐、LLM/API 分组。旧 audio 保留为「音频（待分类）」，不推测其用途；快速模式将旧 audio 改为 TTS 或音乐时保留原时间单价。
2. 默认只在同一模型、相同用户声明参数、相同使用量、目标币种及计价单位集合内比较。同一模型的不同服务商/套餐可进入同组。
3. 跨模型比较需明确填写相同的「共同场景」及参数。该填写代表用户声明可比用途，不代表平台核验生成质量一致。快速模式模型身份来自用户填写的名称；详细模式使用稳定模型 ID。
4. 参数缺失、未知音频类型、价格/汇率缺失、零用量及规则冲突等会提示原因并取消排名。已有可计算的单项成本仍可查看。
5. 输入/输出 Token 单价分别展示，不相加为一个“单位价格”；按指定输入/输出用量计算出的费用可以相加为场景总成本。单位成本图对多分项规则提示没有统一单位成本。
6. 默认隔离每秒和每分钟。选择「按相同用量比较总成本」后，允许在同一可比场景内换算秒/分钟，采用同一时长；单位成本排名及图表始终隔离原计价单位。
7. 同时存在每秒和每分钟两种时间单价时不再重复计费。用户需选择一个作为本次价格；有且仅有一个已填价格时可自动采用。
8. 每组独立排序、独立图表刻度和组内最低标签，没有跨组最低价。单个方案不显示“最低”。输入/输出多分项没有合并后的单位排名。
9. 价格输入清空保留缺失状态，不自动写为零；明确填写 0 与缺失区分。
10. 两种模式保留原本地存储键与 JSON version 1，新增可选 parameters/comparisonScenario/selectedUnit 及 TTS、音乐分钟用量字段。旧 JSON 可导入并保留原价格；参数未知的旧记录不会自动参加排名。

## 模拟数据与实际测试

详细模式「载入示例」提供五类虚构价格结构：图片积分套餐及直接价格、视频秒价、TTS 分钟价、音乐分钟价、LLM 分项输入/输出 Token 单价。页面统一标注模拟价格，模型使用 SIM 名称，不标为真实官方价格。浏览器额外导入同模型第二服务商的视频分钟价，验证等时长比较。

| 检查 | 实际结果 |
|---|---|
| npm run typecheck | 通过 |
| npm test -- --reporter=dot | 139/139 通过，8 个文件；其中新增 P0 13 项 |

| scripts/calculator-p0-check.mjs | 40 组检查通过；中英文 × 1440/390px；页面脚本错误 0 |

13 项核心测试覆盖：五类隔离、同模型多服务商及跨币种、不同参数/模型隔离、明确共同场景、秒/分钟默认隔离与总成本换算、替代时间单价不累加、Token 分项、缺失价格、旧音频与未知参数、TTS/音乐独立用量、旧新 JSON 往返、不同请求用量隔离、零用量及错误汇率。

40 组浏览器检查为 4 种语言/视口组合各 10 组，包含五类分组、详细 JSON 导出/导入、比较依据切换和单位图隔离、快速模式、旧 JSON 导入及导出一致性、清空价格不被当作免费。两种模式均无页面横向溢出（宽表在组件内部横向滚动）。测试使用独立浏览器上下文，不修改用户浏览器存储。

复现（先启动 3001 开发服务）：

```bash
npm run typecheck
npm test -- --reporter=dot
npm run build
node scripts/calculator-p0-check.mjs
```

浏览器脚本需要 Playwright/Chromium；本环境复用既有安装，设置 `PLAYWRIGHT_MODULE=/home/dev-user/projects/earth-radio/node_modules/playwright/index.mjs`，没有添加项目依赖。TEST_URL 可替换默认 http://127.0.0.1:3001。

## 阶段边界

- 当前场景金额是预计消耗成本，不是完整套餐购买金额。积分包数量、198 元支付及 400 积分余额示例将在 P1 实现，不将现有折算值标为实际账单。
- P2 的每字符、每 1M/缓存 Token、每歌曲/生成、订阅、免费额度、超额、阶梯与最低消费尚未完成；当前 TTS 和音乐采用已支持的音频时间价格结构。
- P3 汇率来源/更新时间/基准管理，以及 P4 快速数据转详细、版本校验和导入预览留待相应阶段验收。
- 原 Number/六位小数计算精度未在 P0 全面重构，不将本轮宣称为完整精确十进制计价验收。
- 未修改 D1 数据、Migration、Worker 写接口或部署环境。现有迁移回归测试只在临时内存 SQLite 验证历史 SQL，不代表执行了项目 D1 迁移。
