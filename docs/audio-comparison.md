# TTS 与音乐生成对比

沿用原 Layout、首页和卡片风格新增手动成本对比，不接入核验目录或预填厂商价格。

- TTS：`/zh/compare/tts`、`/en/compare/tts`；支持字符、分钟，字符单价支持每 1 / 1K / 1M 字符。
- 音乐：`/zh/compare/music`、`/en/compare/music`；支持歌曲、生成次数、分钟。
- 入口：原首页场景卡片、工具下拉菜单、工具库分类。原计算器保持不变。
- 最多 6 个方案；按量、月付、年付、可重复购买用量包和免费额度。
- 订阅按用户填写的每月额度计算，超额必须填写明确单价；年付展示全年预付款及月均费用。
- 用量包只适用于当月有效且可重复购买的方案，按整包取整。
- 同单位同币种才计算相对基准的节省；不猜测字符与时长、歌曲与生成次数的换算，不自动换汇。
- 新对比表单是当前页面的临时输入，未接入持久保存；不影响原手动计算器的保存和导入导出。

测试：新增 7 项计价测试，涵盖字符单价归一、单位隔离、超额、年付、整包取整、缺失输入及币种隔离。全量 81 项测试、类型检查和构建通过。
